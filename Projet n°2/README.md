# MQTT Lab — Simulateur MQTT pédagogique

Simulateur MQTT 100 % HTML/CSS/JS, sans dépendance ni serveur : ouvrez `index.html` dans un navigateur.

| Fichier | Contenu |
|---|---|
| `index.html` | Accueil |
| `page1/` | Page 1 : système complet (ESP32 et applications multiples, broker en boîte ouverte, QoS, retain, LWT) |
| `page2/` | Page 2 : connexion simple (un capteur, un broker, un dashboard) |
| `assets/` | Thème, navbar et pied de page partagés (`theme.css`, `site.js`) |

La navbar, le pied de page, l'auteur et les liens se modifient en un seul endroit : `assets/site.js`.
